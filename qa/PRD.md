# 问渠 · 产品需求文档（PRD）

## 1. 定位

一个认真提问、认真回答的技术与产品社区。核心不是「最快得到答案」，而是让问题被完整表达、让回答被认真看见。

## 2. 角色与权限

| 角色 | 权限 |
|---|---|
| 访客 | 浏览问题/回答、排序、标签筛选、搜索、查看用户主页 |
| 登录用户 | 访客权限 + 提问、回答、点赞、采纳自己的问题 |
| 提问者 | 在自己的问题上采纳一个回答 |
| 回答者 | 获得回答积分、被采纳积分、被点赞积分 |

## 3. 核心功能

### 3.1 问题

- 发布问题：标题 5–160 字，描述至少 10 字，1–3 个标签。
- 提问扣 5 积分；积分不足时禁止发布。
- 详情：Markdown 渲染、浏览量 +1、回答列表、点赞状态。
- 列表：最新 / 热门 / 未解决排序。
- 标签筛选、关键词搜索（标题 + 正文）、分页。
- 已解决问题展示「已解决」标记。

### 3.2 回答

- 登录后可回答，内容至少 5 字。
- 回答加 10 积分。
- 回答支持 Markdown。
- 回答按「已采纳 → 点赞数 → 时间」排序。

### 3.3 点赞

- 问题和回答都可以点赞/取消点赞。
- 同一用户对同一目标只能点赞一次。
- 点赞后 `votes + 1`，取消后 `-1`。
- 返回当前用户是否已点赞。
- 被点赞：问题作者 +5，回答作者 +10。
- 不能给自己的内容点赞。

### 3.4 采纳

- 只有提问者可以采纳。
- 每个问题只能采纳一个回答。
- 采纳后回答 `is_accepted = 1`，问题 `is_solved = 1`。
- 回答者 +30 积分。
- 不能采纳自己的回答。

### 3.5 积分

| 行为 | 积分 |
|---|---|
| 注册 | +20 |
| 发布问题 | -5 |
| 回答问题 | +10 |
| 回答被采纳 | +30 |
| 问题被点赞 | +5 |
| 回答被点赞 | +10 |

### 3.6 个人主页与榜单

- 个人主页：积分、提问数、回答数、被采纳数、获赞数、最近提问/回答。
- 首页积分榜：按积分倒序前 6 名。
- 热门标签：按问题数排序。

## 4. 页面

| 路由 | 页面 | 登录 |
|---|---|---|
| `/` | 首页：hero、统计、问题流、标签、积分榜、积分规则 | 否 |
| `/question/:id` | 问题详情、回答列表、回答编辑器、采纳 | 否 |
| `/ask` | 提问页：标题、Markdown 描述、标签、实时预览 | 是 |
| `/profile` | 我的主页 | 是 |
| `/profile/:id` | 他人主页 | 否 |
| `/login` | 登录 | 否 |
| `/register` | 注册 | 否 |

## 5. 交互与状态

- JWT 存 `localStorage`，Axios 统一加 Authorization。
- 未登录点赞/回答/提问跳登录，登录后回到原页面。
- 所有积分变更后刷新 `/auth/me`，保证导航栏积分实时更新。
- 操作反馈使用 Toast；错误信息来自后端。
- 空状态、加载态、404 均有独立设计。
- 移动端 390px 无横向溢出。

## 6. 验收标准

- [ ] 注册初始 20 积分，登录、刷新保持登录态。
- [ ] 提问扣 5 分，问题出现在列表和详情页。
- [ ] 回答加 10 分，回答数 +1，按规则排序。
- [ ] 点赞/取消点赞数量与作者积分同步；重复点击不会重复计数。
- [ ] 非提问者不能采纳；采纳后问题已解决、回答者 +30；重复采纳返回 409。
- [ ] 最新/热门/未解决排序正确；标签筛选、搜索、分页可用。
- [ ] 详情浏览量每次 +1；登录后返回 likedByMe。
- [ ] 个人主页统计正确，不泄露邮箱。
- [ ] 移动端无横向溢出。

## 7. 非目标

评论、关注、通知、全文搜索、徽章、排行榜周期、问题编辑/删除、图片上传属于扩展项，本版不做。
