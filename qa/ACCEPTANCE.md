## 6. 环境说明

- 本地数据库使用 **MariaDB 11.4.13**（与项目一共用），MySQL 协议兼容，`mysql2` 驱动与建表 SQL 按 MySQL 语法编写。
- 切换到标准 MySQL 8 时，修改 `server/.env` 的 `DB_*`，执行 `npm run db:init` 即可。
- 密码使用 `bcryptjs` 实现 bcrypt 算法（cost 12）。
- 当前种子数据：5 个用户、12 个问题、19 个回答、73 条点赞。
- 验收截图中用于走流程的临时问题已在验收后清理，当前数据库只保留种子内容。
