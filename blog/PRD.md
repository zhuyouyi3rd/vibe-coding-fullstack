# 拾语博客 · PRD

## 1. 产品定位

一个安静、克制的个人博客。用户可以注册登录、发布 Markdown 文章、按分类和关键词浏览；访客可以阅读，但不能发布。视觉上强调「像翻一本纸质刊物」，而不是信息流产品。

## 2. 用户角色

| 角色 | 权限 |
|---|---|
| 访客 | 浏览文章列表、详情、分类、搜索、作者主页 |
| 登录用户 | 访客权限 + 发布文章、编辑/删除自己的文章、编辑个人资料、修改密码 |
| 文章作者 | 只能编辑、删除自己发布的文章 |

## 3. 核心功能

### 3.1 用户

- 注册：用户名（3–20 字符，唯一）、邮箱（唯一）、密码（至少 6 位）。
- 登录：用户名 + 密码，返回 JWT，有效期 7 天。
- 个人中心：查看头像、用户名、加入时间、文章数、总阅读量。
- 编辑资料：用户名、邮箱、头像。
- 修改密码：校验当前密码。

### 3.2 文章

- 发布：标题、Markdown 正文、分类、标签（最多 8 个）、封面。
- 编辑：只能编辑自己的文章。
- 删除：只能删除自己的文章，二次确认。
- 详情：渲染 Markdown，浏览量 +1。
- 列表：分页（每页 10 条）、分类筛选、关键词搜索（标题/正文）。
- 作者主页：展示该作者的文章，每页 6 条。

### 3.3 页面

| 路由 | 页面 | 是否登录 |
|---|---|---|
| `/` | 首页：Hero、推荐、分类索引、文章流、搜索 | 否 |
| `/post/:id` | 文章详情、目录、作者卡片、相关文章 | 否 |
| `/write` | 新建文章，左编辑右预览 | 是 |
| `/write/:id` | 编辑文章，回填数据 | 是 |
| `/profile` | 个人中心：文章管理、资料、密码 | 是 |
| `/author/:id` | 作者主页 | 否 |
| `/login` | 登录 | 否 |
| `/register` | 注册 | 否 |

## 4. 交互与状态

- 登录态：JWT 存 `localStorage`，Axios 请求拦截器统一加 `Authorization`。
- 路由保护：`ProtectedRoute` 未登录跳转登录页，登录后回到原页面。
- 反馈：保存/删除/资料更新使用 Toast；删除文章有确认弹层。
- 空状态：无文章、搜索无结果、作者无文章分别有对应提示。
- 响应式：桌面三列文章卡、移动端单列；编辑器在移动端上下堆叠。

## 5. 验收标准

- [ ] 注册、登录、退出正常，刷新后登录态保持。
- [ ] 未登录访问 `/write`、`/profile` 会跳转登录。
- [ ] 发布文章后出现在首页，详情页 Markdown 正确渲染。
- [ ] 列表分页、分类筛选、关键词搜索均有效。
- [ ] 详情页浏览量每次访问 +1。
- [ ] 非作者看不到编辑/删除按钮；直接调用接口也会被 403 拒绝。
- [ ] 编辑文章能回填，保存后详情更新。
- [ ] 删除文章二次确认，删除后列表不再出现。
- [ ] 个人资料、密码修改可用。
- [ ] 移动端 375px 宽度无横向溢出。

## 6. 非目标

- 评论、点赞、草稿、图片上传、RSS、SEO 属于扩展项，第一版不做。
- 不接第三方登录，不做邮箱验证。
