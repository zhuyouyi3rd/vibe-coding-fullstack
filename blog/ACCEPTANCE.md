## 6. 本地环境说明

- 本机原先没有 MySQL 服务，为了让项目可直接验收，使用了 **MariaDB 11.4.13**（MySQL 协议兼容，`mysql2` 驱动与建表 SQL 均按 MySQL 语法编写）。
- 本地数据库已配置为一键启动：`npm run db:start`；启动脚本会检测 3307 端口，未运行时自动拉起 `.runtime` 中的 MariaDB。
- 如切换到标准 MySQL 8，只需修改 `server/.env` 的 `DB_HOST / DB_PORT / DB_USER / DB_PASSWORD / DB_NAME`，然后执行 `npm run db:init`。
- 密码哈希使用 `bcryptjs` 实现 bcrypt 算法（cost 12），与 `bcrypt` 算法兼容；这样避免 Windows 本地原生模块编译问题。
- 数据库结构见 `database.md`，建表 SQL 见 `server/db/schema.sql`。
