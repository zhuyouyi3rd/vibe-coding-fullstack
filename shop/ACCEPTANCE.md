## 6. 环境说明

- 本地数据库使用 **MariaDB 11.4.13**（与项目一、二共用），MySQL 协议兼容。
- 切换到标准 MySQL 8 时，修改 `server/.env` 的 `DB_*`，执行 `npm run db:init`。
- 密码使用 `bcryptjs` 实现 bcrypt（cost 12）。
- 当前种子数据：2 用户、8 商品、1 地址、1 历史订单。
- 验收截图中的临时订单/地址已在验收后清理。

## 7. 本版未包含（扩展项）

支付、优惠券、商品评价、物流跟踪、商家后台、推荐算法。

## 8. 请验收

1. 打开 http://127.0.0.1:4201，切换分类、搜索、排序。
2. 打开商品详情，加入购物车。
3. 进入购物车，修改数量，确认金额与运费。
4. 提交订单，查看待支付订单与商品/地址快照。
5. 取消订单，确认状态变为已取消、库存恢复。
6. 打开收货地址，新增/编辑/删除地址，观察默认地址变化。
7. 用 390px 宽度检查移动端无横向滚动。
