# 云市 · 产品需求文档（PRD）

## 1. 定位

一间小而克制的线上杂货铺，售卖家居、咖啡、织物、香氛类日常用品。本版为 Mini 商城，覆盖「浏览商品 → 加购 → 填地址 → 下单 → 查看/取消订单」的交易主流程，不接支付。

## 2. 用户角色

| 角色 | 权限 |
|---|---|
| 访客 | 浏览商品、分类、搜索、商品详情 |
| 登录用户 | 加购、改数量、删除、管理地址、下单、查看/取消自己的订单 |

## 3. 核心功能

### 3.1 商品

- 商品列表：分类筛选、关键词搜索、价格升/降序。
- 商品详情：图片、名称、价格、库存、描述、数量选择。
- 库存不足时不可加购/增加数量。
- 加入购物车需要登录；未登录跳登录页。

### 3.2 购物车

- 加入商品：同商品数量累加，校验库存。
- 修改数量：1 到库存上限。
- 删除商品。
- 显示商品金额、运费、应付总额。
- 满 299 元免运费，否则 12 元。

### 3.3 收货地址

- 新增地址；首个地址自动设为默认。
- 设置新默认地址时，清除旧默认。
- 编辑、删除地址；删除默认地址后，剩余第一个自动补默认。
- 手机号 11 位校验。

### 3.4 订单

- 创建订单：选择地址 + 当前购物车全部商品。
- 创建后状态为「待支付」，不实现支付。
- 订单列表支持全部/待支付/已支付/已发货/已完成/已取消筛选。
- 订单详情：订单号、状态、商品清单、金额、收货信息、状态时间线。
- 取消订单：只允许待支付；取消后恢复库存。
- 订单商品保存下单时名称、图片、价格快照。

## 4. 页面

| 路由 | 页面 | 登录 |
|---|---|---|
| `/` | 首页：hero、分类、商品网格、品牌故事 | 否 |
| `/product/:id` | 商品详情、同类推荐 | 否 |
| `/cart` | 购物车、地址选择、提交订单 | 是 |
| `/orders` | 订单列表、状态筛选 | 是 |
| `/orders/:id` | 订单详情、取消订单 | 是 |
| `/addresses` | 地址列表、新增/编辑/删除 | 是 |
| `/login` | 登录 | 否 |
| `/register` | 注册 | 否 |

## 5. 交互与状态

- JWT 存 localStorage，Axios 自动带 token。
- 购物车数量在导航栏实时显示；下单后刷新为 0。
- 地址、订单操作均有 Toast 反馈。
- 删除地址、取消订单有二次确认。
- 加载态、空购物车、空订单、404 均有独立状态。
- 移动端 390px 无横向溢出。

## 6. 验收标准

- [ ] 商品列表 8 件，分类/搜索/排序正常。
- [ ] 未登录加购跳登录。
- [ ] 同商品重复加购数量累加；超库存返回 400。
- [ ] 购物车改数量、删除、金额/运费正确。
- [ ] 首个地址自动默认；新默认替换旧默认；删除默认后自动补位。
- [ ] 下单后：订单状态待支付、库存扣减、购物车清空、购物车角标归零。
- [ ] 订单号唯一；订单商品/地址有快照。
- [ ] 订单列表状态筛选、详情、越权访问（404）。
- [ ] 取消待支付订单恢复库存；重复取消返回 409。
- [ ] 移动端无横向溢出。

## 7. 非目标

支付、优惠券、商品评价、物流跟踪、商家后台、商品推荐算法属于扩展项，本版不做。
